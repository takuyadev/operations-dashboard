# operations-dashboard

# Features
- Admin dashboard for operations center staff
- Emit event when backend analysis system detects potential emergency on the road
- Display decision to dispatch response team
- Visibility is key in the operations dashboard

## Event Details
- Priority
- Location
- Snapshot image
- Description of what was detected

## Situation
- Traffic accident
- Debris on road
- Vehicle travelling in the wrong direction

# Install Project
This project is setup with Docker, and can be intialized with the following command:

```docker compose up -d```
